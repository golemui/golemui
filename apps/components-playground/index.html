GolemUI Components playground

The elements on their own: plain HTML, no framework and no form. Each page writes the markup an app would write. The toolbar switches the theme, the direction of the whole page, the built-in strings and the way overlays are placed; the box in the corner logs the events.

npm run start:components serves the pages as you edit them. npx nx run components-playground:preview builds them and serves them under a strict Content Security Policy (default-src 'self'), as a careful app ships.
