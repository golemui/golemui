GolemUI Components playground

The elements on their own: plain HTML, no framework and no form. Each page writes the markup an app would write. The toolbar switches the theme, the direction of the whole page, the built-in strings and the way overlays are placed; the box in the corner logs the events.

npm run start:components serves the pages as you edit them. npx nx run components-playground:preview builds them and serves them under a strict Content Security Policy (default-src 'self'), as a careful app ships.

Elements

  • Dialog A form in a modal, drawers on every edge, an alert dialog and a long dialog that scrolls inside.
  • Menu Row actions, a "more" menu at a row's end, links and disabled items, right to left and a menu in a dialog.
  • One-time code A verification code drawn as boxes: paste, autofill, groups, lengths, errors and a form.
  • Pickers and dropdowns Every picker and dropdown, in a clipping box, a modal dialog, a drawer, a popover and docked at the bottom of the window.
  • Popover A panel anchored to the button that opens it: placements, edges, right to left, scrolling and modal dialogs.
  • Slider A slider and a range slider: steps, marks, number formats, the value bubble, no value until moved, and both in a form.
  • Toast Variants, an Undo action, a queue, updates in place, every placement and toasts above a modal dialog.
  • Tooltip Hover and keyboard focus, every placement, a tooltip you can move onto, right to left and an unavailable control.
