gui-dialog

The app's own <dialog>, opened as a modal: the page behind it is inert and stops scrolling, Escape closes it, and focus goes back to the button that opened it. The buttons use invoker commands (commandfor), so they need no script.

A form in a dialog

The pickers' panels and the tooltip float above the dialog's edges.

Drawers

Each one is dismissible: a click on the backdrop closes it too. Switch the direction in the toolbar: start and end swap. Each one focuses its heading first (autofocus), so a screen reader announces the drawer before its fields.
