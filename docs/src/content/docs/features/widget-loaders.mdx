Widget loaders are a `Record<string, () => Promise<unknown>>` map that tells the form engine how to lazy-load each widget kind. The map key is the widget `type` (e.g. `'textinput'`, `'dropdown'`) and the value is an async loader that returns the widget implementation.

Each framework adapter exports a default `widgetLoaders` object preloaded with the GolemUI widget set. You always start from that and merge in your own custom widgets as needed. **Where** that map lives on the form component depends on which path you took to define the form.

## Default loaders

<DslTabs>
  <Fragment slot="dx">

In the Programmatic API, widget loaders go inside `formConfig.widgetLoaders`. The form component reads them through `formConfig`.

<IntegrationTabs>
  <Fragment slot="react">
    ```tsx
    import { gui } from '@golemui/gui-shared';
    import * as React from '@golemui/gui-react';

    const formDef = [gui.inputs.textInput('username')];
    const formConfig = { widgetLoaders: React.widgetLoaders };

    export function MyForm() {
      return (
        <GuiForm
          formDef={formDef}
          data={{}}
          formConfig={formConfig}
        />
      );
    }
    ```

  </Fragment>
  <Fragment slot="angular">
    ```ts
    import { Component } from '@angular/core';
    import { CommonModule } from '@angular/common';
    import { gui } from '@golemui/gui-shared';
    import * as Angular from '@golemui/gui-angular';

    @Component({
      imports: [CommonModule, Angular.FormComponent],
      selector: 'app-my-form',
      template: `<gui-form
        [formDef]="formDef"
        [data]="formData"
        [formConfig]="formConfig"
      ></gui-form>`,
    })
    export class MyForm {
      protected formDef = [gui.inputs.textInput('username')];
      protected formData = {};
      protected formConfig = { widgetLoaders: Angular.widgetLoaders };
    }
    ```

        return html`

      }
    }

The exported map covers every built-in input, layout, display, and action widget for that framework.

## Adding custom widgets

Spread the defaults and add your own loader entries to the same map. The key (e.g. `productCard`) must match the `type` field on the widget instances in your `formDef`.

<DslTabs>
  <Fragment slot="dx">

The `formConfig.widgetLoaders` object now carries both the defaults and your custom entries.

<IntegrationTabs>
  <Fragment slot="react">
    ```tsx
    import { gui } from '@golemui/gui-shared';
    import * as React from '@golemui/gui-react';

    const formDef = [
      gui.layouts.custom('productCard', [/* children */], { title: 'My product' }),
    ];

    const formConfig = {
      widgetLoaders: {
        ...React.widgetLoaders,
        productCard: async () =>
          (await import('./widgets/ProductCard')).ProductCard,
      },
    };

    export function MyForm() {
      return (
        <GuiForm
          formDef={formDef}
          data={{}}
          formConfig={formConfig}
        />
      );
    }
    ```

  </Fragment>
  <Fragment slot="angular">

The `customWidgetLoaders` prop carries both the defaults and your custom entries. The JSON itself references the widget by `"type": "productCard"`.

```json
{
  "form": [
    {
      "kind": "layout",
      "type": "productCard",
      "props": { "title": "My product" },
      "items": []
    }
  ]
}
```

Widget loaders use dynamic `import()` so custom widgets are **lazy-loaded** — they're only fetched when the form engine encounters them.
