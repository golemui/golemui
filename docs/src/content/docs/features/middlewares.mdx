Middlewares are functions that wrap the form's reactive store and observe (or mutate) every action that flows through it. They run on every state change and can be composed.

`middlewares` goes inside the `config` object in both paths.

## Default middlewares

GolemUI ships a few middlewares you can opt into:

| Middleware           | What it does                                                                        |
| -------------------- | ----------------------------------------------------------------------------------- |
| `loggerMiddleware`   | Logs each action and the resulting state to the console — handy during development. |
| `devToolsMiddleware` | Pipes actions to the Redux DevTools extension for time-travel debugging.            |

## Wiring middlewares

Pass an array of middlewares inside the `config` object as the `middlewares` property. Below, every framework wires `devToolsMiddleware`.

  <Fragment slot="react">
    ```tsx
    import * as Core from '@golemui/core';
    import { gui } from '@golemui/gui-shared';
    import * as React from '@golemui/gui-react';

    const formDef = [gui.inputs.textInput('username')];
    const formConfig = { widgetLoaders: React.widgetLoaders };
    const middlewares = [Core.devToolsMiddleware()];
    const config = { formDef, data: {}, formConfig, middlewares };

    export function MyForm() {
      return <GuiForm config={config} />;
    }
    ```

  <Fragment slot="angular">
    ```ts
    import { Component } from '@angular/core';
    import { CommonModule } from '@angular/common';
    import * as Core from '@golemui/core';
    import { gui } from '@golemui/gui-shared';
    import * as Angular from '@golemui/gui-angular';

    @Component({
      imports: [CommonModule, Angular.FormComponent],
      selector: 'app-my-form',
      template: `<gui-form [config]="config"></gui-form>`,
    })
    export class MyForm {
      protected config = {
        formDef: [gui.inputs.textInput('username')],
        data: {},
        formConfig: { widgetLoaders: Angular.widgetLoaders },
        middlewares: [Core.devToolsMiddleware()],
      };
    }
    ```

  </Fragment>
  <Fragment slot="lit">
    ```ts
    import { LitElement, html } from 'lit';
    import { customElement } from 'lit/decorators.js';
    import * as Core from '@golemui/core';
    import { gui } from '@golemui/gui-shared';
    import * as Lit from '@golemui/gui-lit';

    @customElement('my-form')
    export class MyForm extends LitElement {
      config = {
        formDef: [gui.inputs.textInput('username')],
        data: {},
        formConfig: { widgetLoaders: Lit.widgetLoaders },
        middlewares: [Core.devToolsMiddleware()],
      };

      override createRenderRoot() { return this; }

      override render() {
        return html`<gui-form .config=${this.config}></gui-form>`;
      }
    }
    ```
