Checkbox components are [Input Fields](/components-reference/input-fields/overview) that allow the user to toggle boolean (true/false) values. They are usually used to represent an "on/off" state.

## Props

Use these `props` to customize your Checkbox component.

| prop               | type   | description                                                                                      |
| ------------------ | ------ | ------------------------------------------------------------------------------------------------ |
| `hint`             | string | A description to display below the checkout input                                                |
| `checkboxPosition` | string | Position of the checkbox relative to its label. Possible values are `left` or `right` (default). |

Use the property `hint` to add a description.

## Styling

Checkboxes can be styled as explained in the [Styling Guide](/guides/styling).

### CSS Variables

Following you will find a list with the CSS Variables and a quick description of what you will style.

| CSS Variable             | Description                                |
| ------------------------ | ------------------------------------------ |
| `--gui-radius-sm`        | Checkbox box border radius                 |
| `--gui-intent-primary`   | Checkbox checked background and tick color |
| `--gui-space-gap--inner` | Label gap and margin bottom                |
