## Props

Use these `props` to customize your Range Calendar component. Range Calendars share all properties with standard [Calendars](/components-reference/input-fields/calendar).

| prop             | type   | description                                                                        |
| ---------------- | ------ | ---------------------------------------------------------------------------------- |
| `hint`           | string | A description to display below the range calendar                                  |
| `minDate`        | string | Minimum allowable date in ISO format                                               |
| `maxDate`        | string | Maximum allowable date in ISO format                                               |
| `numberOfMonths` | number | Number of months to display simultaneously. Defaults to 2 for range calendars      |
| `disabledRanges` | array  | Array of objects (`{ start: string, end?: string }`) defining disabled date ranges |

## Styling

Range Calendars can be styled as explained in the [Styling Guide](/guides/styling). They inherit all Calendar component styles along with specialized range highlighting rules.

### CSS Variables

Following you will find a list with the CSS Variables and a quick description of what you will style.

| CSS Variable           | Description                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------- |
| `--gui-radius-md`      | Calendar container base radius                                                                    |
| `--gui-radius-range`   | Border radius applied to the start and end of a selected range (calculated as double `radius-md`) |
| `--gui-intent-primary` | Selected range, range start, and range end background color                                       |
