Repeater components are powerful [Layout Fields](/components-reference/layout-fields/overview) that enable dynamic list management. They take a `template` widget and allow users to create multiple entries of that widget, which are then stored as an array of objects in the form state.

## Props

Use these `props` to customize your Repeater component.

| prop          | type   | description                                                       |
| ------------- | ------ | ----------------------------------------------------------------- |
| `template`    | object | **Required**. The widget definition (JSON) that will be repeated  |
| `addLabel`    | string | Label for the button that adds a new item. Defaults to `"Add"`    |
| `removeLabel` | string | Label for the button that removes an item. Defaults to `"Remove"` |
| `limit`       | number | Maximum number of items allowed in the list                       |

### Item Limit

You can restrict the number of items a user can add using the `limit` property. Once the limit is reached, the "Add" button is automatically disabled.

## Styling

Repeaters can be styled as explained in the [Styling Guide](/guides/styling).

### CSS Variables

Following you will find a list with the CSS Variables used to style the repeater cards.

| CSS Variable           | Description                               |
| ---------------------- | ----------------------------------------- |
| `--gui-bg-default`     | Background color for the item cards       |
| `--gui-border-default` | Border color for the item cards           |
| `--gui-radius-md`      | Border radius for the item cards          |
| `--gui-space-3`        | Spacing and padding for cards and buttons |
