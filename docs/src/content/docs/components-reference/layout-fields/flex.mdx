Flex components are [Layout Fields](/components-reference/layout-fields/overview) that use CSS Flexbox to arrange child widgets using standard CSS `flex-direction` values. They are the primary tool for building responsive form layouts.

## Props

Use these `props` to customize your Flex component.

| prop        | type   | description                                                                                                                  |
| ----------- | ------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `direction` | string | CSS flex-direction: `'row'`, `'row-reverse'`, `'column'`, or `'column-reverse'`. Defaults to `'column'`                      |
| `align`     | string | Alignment of children: `'start'`, `'end'`, `'center'`, `'space-between'`, `'space-around'`                                  |
| `gap`       | number | Space between children in pixels (Implementation may vary)                                                                   |

### Row Layout

Set `direction` to `"row"` to place child widgets side-by-side. On small screens (max-width: 480px), row layouts automatically stack vertically for better mobile usability.
