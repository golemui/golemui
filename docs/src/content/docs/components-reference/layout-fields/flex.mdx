Flex components are [Layout Fields](/components-reference/layout-fields/overview) that use CSS Flexbox to arrange child widgets either horizontally or vertically. They are the primary tool for building responsive form layouts.

## Props

Use these `props` to customize your Flex component.

| prop        | type   | description                                                                                |
| ----------- | ------ | ------------------------------------------------------------------------------------------ |
| `direction` | string | Either `'horizontal'` or `'vertical'`. Defaults to `'vertical'`                            |
| `align`     | string | Alignment of children: `'start'`, `'end'`, `'center'`, `'space-between'`, `'space-around'` |
| `gap`       | number | Space between children in pixels (Implementation may vary)                                 |

### Horizontal Layout

Set `direction` to `"horizontal"` to place child widgets side-by-side. On small screens (max-width: 480px), horizontal layouts automatically stack vertically for better mobile usability.
