## Props

Use this `props` to customize your Checkbox component.

| prop               | type   | value                                                        |
| ------------------ | ------ | ------------------------------------------------------------ |
| `checkboxPosition` | string | The checkbox position, possible values are `right` or `left` |

### Checkbox Position

Use the property `checkboxPosition` to add align the checkbox input to `left` or `right`.

## Styling

Checkboxes can be styled as explained in the [Styling Guide](/guides/styling).

### CSS Variables

Following you will find a list with the CSS Variables and a quick description of what you will style.

| CSS Variable           | Description                       |
| ---------------------- | --------------------------------- |
| `--ff-color-border`    | Input border color                |
| `--ff-checkbox-radius` | Checkbox radius                   |
| `--ff-color-primary`   | Accent color and box shadow color |
