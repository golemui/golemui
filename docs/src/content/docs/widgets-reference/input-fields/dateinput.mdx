Date Input widgets are [Input Fields](/widgets-reference/input-fields/overview) that provide a structured, segmented text-input approach to manual date entry, offering a keyboard-friendly alternative to interactive calendars. The date segments automatically localize based on the user's region and locale.

## Props

Use these `props` to customize your Date Input widget.

| prop   | type   | description                                         |
| ------ | ------ | --------------------------------------------------- |
| `hint` | string | A description to display below the segmented inputs |
| `icon` | string | A css class to display an icon inside the input     |

### Hint

<Aside>A `label` is required for the `hint` to be displayed.</Aside>

Use the property `hint` to add a description or validation instructions.

<DslCode dxCode={dateinputHintDx} jsonCode={dateinputHintJson} dxTitle={configDx} jsonTitle={configJson} />

### Icon

Use the property `icon` to add an icon to the widget. The value of `icon` represents a set of CSS classes separated by spaces. The icon is displayed inside the input border.

## Styling

Date Inputs can be styled as explained in the [Styling Guide](/guides/styling).

### CSS Variables

Following you will find a list with the CSS Variables and a quick description of what you will style.

| CSS Variable         | Description                                                                    |
| -------------------- | ------------------------------------------------------------------------------ |
| `--gui-intent-error` | Border and focus shadow color when invalid                                     |
| `--gui-text-default` | Active piece (day/month/year) visual underline color and standard focus shadow |
