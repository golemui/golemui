Dropdown widgets are [Input Fields](/widgets-reference/input-fields/overview) that provide a searchable list of items. Users can either type in the input to filter the list or select an item directly from the interactive dropdown menu.

## Props

Use these `props` to customize your Dropdown widget.

| prop            | type   | description                                                                                                            |
| --------------- | ------ | ---------------------------------------------------------------------------------------------------------------------- |
| `items`         | array  | **Required**. Array of items to be displayed in the dropdown list                                                      |
| `placeholder`   | string | Text shown in the input when it is empty                                                                               |
| `hint`          | string | A description to display below the input                                                                               |
| `labelField`    | string | Field to use for the display label when items are objects                                                              |
| `valueField`    | string | Field to use for the value when items are objects                                                                      |
| `searchFields`  | array  | List of fields to search on when filtering the list                                                                    |
| `height`        | number | Height of the dropdown list container                                                                                  |
| `itemHeight`    | number | Height of each individual item in the list                                                                             |
| `itemRenderer`  | string | Key of a registered renderer used to draw each item. See [Item Renderers](/features/item-renderers/)                   |
| `inputDebounce` | number | Delay in milliseconds before triggering a search/filter. Defaults to `500`                                             |
| `autocomplete`  | string | `'on'`, `'off'`, or a space-separated list of W3C autofill tokens                                                      |

### Item Renderer

Use the property `itemRenderer` to draw each row with a registered renderer instead of the default template. The key must match one of the renderers registered on the form host — see [Item Renderers](/features/item-renderers/) for the full setup.

This demo uses the registered `countryItemRenderer` to display each country with its flag.

### Size

Use `height` to set the size of the dropdown's scrollable list, and `itemHeight` to fix the row height used by the virtual scroller. Tune `itemHeight` whenever you use a custom `itemRenderer` whose rows are taller than the default.

### Input Debounce

Use `inputDebounce` to control how long the dropdown waits after each keystroke before applying the filter. Useful when the `filter` event triggers a server-side search.

### Autocomplete

Use `autocomplete` to set the underlying input's `autocomplete` attribute. Accepts `'on'`, `'off'`, or a space-separated list of [W3C autofill tokens](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#autofill).

## Styling

Dropdowns can be styled as explained in the [Styling Guide](/styling/overview/).

### CSS Variables

Dropdowns leverage standard container and list variables.

| CSS Variable           | Description                     |
| ---------------------- | ------------------------------- |
| `--gui-radius-md`      | Border radius for the container |
| `--gui-border-default` | Default border color            |
