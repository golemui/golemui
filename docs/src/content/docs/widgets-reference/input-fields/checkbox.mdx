Checkbox widgets are [Input Fields](/widgets-reference/input-fields/overview) that allow the user to toggle boolean (true/false) values. They are usually used to represent an "on/off" state.

## Props

Use these `props` to customize your Checkbox widget.

| prop               | type   | description                                                                                      |
| ------------------ | ------ | ------------------------------------------------------------------------------------------------ |
| `hint`             | string | A description to display below the checkout input                                                |
| `checkboxPosition` | string | Position of the checkbox relative to its label. Possible values are `left` (default) or `right`. |

### Hint

<Aside>A `label` is required for the `hint` to be displayed.</Aside>

Use the property `hint` to add a description.

Use the property `checkboxPosition` to put the checkbox to the `left` (default) or `right` of its label.

## Styling

Checkboxes can be styled as explained in the [Styling Guide](/styling/overview/).

### CSS Variables

Following you will find a list with the CSS Variables and a quick description of what you will style.

| CSS Variable           | Description                                |
| ---------------------- | ------------------------------------------ |
| `--gui-radius-sm`      | Checkbox box border radius                 |
| `--gui-intent-primary` | Checkbox checked background and tick color |
