Markdown Text widgets are [Display Fields](/widgets-reference/display-fields/overview) used to render structured and formatted content as HTML. They are non-interactive and purely informational. Use them when you need to display rich content such as headings, lists, bold text, links, or any other markdown-formatted text — as opposed to `alert`, which is designed for short status messages.

## Dependencies

The Markdown Text widget requires a markdown parser to render formatted HTML. Since the parser is a third-party dependency, it is **not bundled** with the widget. Instead, you provide it at the form level via the `dependencies` property, keeping the core library decoupled from any specific parser.

<Aside type="tip">
  You can use any markdown parser that exposes a `(markdown: string) => string` function, such as [snarkdown](https://github.com/developit/snarkdown), [marked](https://github.com/markedjs/marked), or [micromark](https://github.com/micromark/micromark).
</Aside>

Pass the markdown parser through `formConfig.dependencies` on the form component, not inside the widget's `props`:

<IntegrationTabs>

    import snarkdown from 'snarkdown';

<Aside>The markdown content will only be rendered as HTML when a `dependencies.markdown.parse` function is provided. Without it, the widget renders nothing.</Aside>

## Security

<Aside type="caution">
  **You are responsible for sanitizing the markdown content.** The parse function output is injected as raw HTML. This is consistent with the approach recommended by most markdown libraries (e.g. [marked](https://marked.js.org/using_advanced#options), [micromark](https://github.com/micromark/micromark#security)).

Use a sanitization library such as [DOMPurify](https://github.com/cure53/DOMPurify) inside your `parse` function to prevent XSS attacks:

```typescript
import DOMPurify from 'dompurify';
import { marked } from 'marked';

const formConfig = {
  dependencies: {
    markdown: {
      parse: (md: string) => DOMPurify.sanitize(marked(md) as string),
    },
  },
};
```

</Aside>

## Styling

Markdown Text can be styled as explained in the [Styling Guide](/styling/overview/).

### CSS Variables

The following CSS custom properties control the visual appearance of rendered markdown content. Override them to match your design system.

| CSS Variable                       | Description                                |
| ---------------------------------- | ------------------------------------------ |
| `--gui-md-text-color`              | Base text color                            |
| `--gui-md-line-height`             | Base line height                           |
| `--gui-md-heading-color`           | Color for h1–h6 headings                   |
| `--gui-md-heading-weight`          | Font weight for headings                   |
| `--gui-md-link-color`              | Link text color                            |
| `--gui-md-link-hover-color`        | Link color on hover                        |
| `--gui-md-blockquote-bg`           | Blockquote background                      |
| `--gui-md-blockquote-border-color` | Blockquote left border color               |
| `--gui-md-blockquote-color`        | Blockquote text color                      |
| `--gui-md-code-bg`                 | Background for inline code and code blocks |
| `--gui-md-code-color`              | Text color for inline code and code blocks |
| `--gui-md-code-radius`             | Border radius for inline code              |
| `--gui-md-hr-color`                | Color of horizontal rules                  |

All tokens reference semantic tokens from the design system and adapt automatically in dark mode. See the full reference in [Design Tokens — Markdown Text](/styling/design-tokens/#markdown-text).
