GolemUI is a blazing fast JavaScript library for building dynamic forms from JSON files or other data sources. It provides a free set of UI widgets with support for React, Angular, and Lit.

### Create your first dynamic form

Creating a dynamic form has never been this easy.

<Steps>

1.  ##### Install GolemUI and the Golem Widgets:

    Choose the framework you want to use for your project.

    <IntegrationTabs>
      <Fragment slot="react">
        ```bash
        npm i @golemui/core @golemui/react @golemui/gui-react --save
        ```
      </Fragment>
      <Fragment slot="angular">
        ```bash
        npm i @golemui/core @golemui/angular @golemui/gui-angular --save
        ```
      </Fragment>
      <Fragment slot="lit">
        ```bash
        npm i @golemui/core @golemui/lit @golemui/gui-lit --save
        ```
      </Fragment>
    </IntegrationTabs>

2.  ##### Import the Golem Widgets styles:

    You can load the CSS file directly in your HTML or import it in your Sass/CSS file.

    ```scss
    @import '@golemui/core/styles/index.css';
    ```

3.  ##### Create your first dynamic form:

    Create a component that renders a form using the `FormComponent`.

    <DslTabs>
      <Fragment slot="dx">
        <IntegrationTabs>
          <Fragment slot="react">
            ```ts
            import { gui } from '@golemui/gui-shared';

            const formDef = [gui.inputs.textInput('username')];
            const formData = { username: 'golemui' };
            const formConfig = { widgetLoaders: GuiReact.widgetLoaders };

            export function FormPage() {
              return (
               <div>
                <React.FormComponent
                  formDef={formDef}
                  data={formData}
                  formConfig={formConfig}
                />
               </div>
              );
            }
            ```
          </Fragment>
          <Fragment slot="angular">
            ```ts
            import { gui } from '@golemui/gui-shared';

            @Component({
              imports: [CommonModule, Angular.FormComponent],
              selector: 'app-dynamic-form',
              template: `<gui-form
                [formDef]="formDef"
                [data]="formData"
                [formConfig]="formConfig"
              >
              </gui-form>`,
            })
            export class AppFormPage {
              protected formDef = [gui.inputs.textInput('username')];
              protected formData = { username: 'golemui' };
              protected formConfig = { widgetLoaders: GuiAngular.widgetLoaders };
            }
            ```
          </Fragment>
          <Fragment slot="lit">
            ```ts
            import { gui } from '@golemui/gui-shared';

            @customElement('lit-form')
            export class FormElement extends LitElement {
              formDef = [gui.inputs.textInput('username')];
              formData = { username: 'golemui' };
              formConfig = { widgetLoaders: GuiLit.widgetLoaders };

              override createRenderRoot() {
                return this;
              }

              render() {
                return html`
                  <div>
                    <gui-form
                      .formDef=${this.formDef}
                      .data=${this.formData}
                      .formConfig=${this.formConfig}
                    ></gui-form>
                  </div>
                `;
              }
            }
            ```
          </Fragment>
        </IntegrationTabs>

      </Fragment>
      <Fragment slot="json">
        Create a JSON file with your form definition:

        ```json
        {
          "form": [
            {
              "kind": "input",
              "type": "textinput",
              "path": "username"
            }
          ]
        }
        ```

        Then load and render it in your framework. See the [Integration](/integration/overview/) section for framework-specific setup.

      </Fragment>
    </DslTabs>

4.  ##### That's it!

    You can now see your form rendered in the browser.

    <Demo src="/template/index.html?form=template/getting-started/quick-start.json" />

</Steps>
