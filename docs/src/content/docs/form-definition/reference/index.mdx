## Conceptual walkthrough

If you're new to the Form Definition API, read the conceptual pages first — the reference is a dictionary, not a tutorial.

- **[How it works](/form-definition/how-it-works/)** — the user-facing tour of `gui.*`, signatures, and the building blocks.
- **[Tags](/form-definition/tags/)** — labelling widgets so the selector layer can target them.
- **[Custom Widgets](/form-definition/custom-widgets/)** — `gui.<group>.custom(...)` for widgets you've implemented yourself.
- **[States](/form-definition/states/)** — named conditions plus `include` / `exclude` / `when` for gating widgets.
- **[Runtime Functions](/form-definition/runtime-functions/)** — make any prop reactive by passing a callback instead of a static value.
- **[Events](/form-definition/events/)** — `onClick`, `onChange`, `onLoad`, `onFilter`, `onBlur`, plus the special `submit`.
- **[Selectors](/form-definition/selectors/)** — the behavior layer that decorates widgets by type, tag, or uid.
