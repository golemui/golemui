GolemUI is a blazing fast JavaScript library for building dynamic forms from JSON files. It provides a free set of UI widgets with support for React, Angular, Lit, and Vue.

This guide walks you from an empty directory to a rendered form in five steps.

<Aside type="tip" title="Want to skip ahead?">

<Steps>

1.  ##### Scaffold a new project

    Use Vite (or your favourite scaffolder) to create a fresh project for your framework. For example, with Vite:

    <IntegrationTabs>
      <Fragment slot="react">
        ```bash
        npm create vite@latest my-form -- --template react-ts
        cd my-form && npm install
        ```
      </Fragment>
      <Fragment slot="angular">
        ```bash
        npx @angular/cli new my-form
        cd my-form
        ```
      </Fragment>
      <Fragment slot="lit">
        ```bash
        npm create vite@latest my-form -- --template lit-ts
        cd my-form && npm install
        ```
      </Fragment>
      <Fragment slot="vue">
        ```bash
        npm create vite@latest my-form -- --template vue-ts
        cd my-form && npm install
        ```
      </Fragment>
    </IntegrationTabs>

2.  ##### Install GolemUI and the Golem Widgets

    Pick the adapter package for the framework you're using.

    <IntegrationTabs>
      <Fragment slot="react">
        ```bash
        npm i @golemui/gui-react --save
        ```
      </Fragment>
      <Fragment slot="angular">
        ```bash
        npm i @golemui/gui-angular --save
        ```
      </Fragment>
      <Fragment slot="lit">
        ```bash
        npm i @golemui/gui-lit --save
        ```
      </Fragment>
      <Fragment slot="vue">
        ```bash
        npm i @golemui/gui-vue --save
        ```
      </Fragment>
    </IntegrationTabs>

    This installs the adapter along with all its peer dependencies.
    - **GolemUI packages** (shared across all adapters): `@golemui/core`, `@golemui/gui-shared`, `@golemui/gui-components`, `@golemui/gui-validators`.

    - **GolemUI Framework adapter**: <FrameworkContent inline><Fragment slot="react">`@golemui/react`</Fragment><Fragment slot="angular">`@golemui/angular`</Fragment><Fragment slot="lit">`@golemui/lit`</Fragment><Fragment slot="vue">`@golemui/vue`</Fragment></FrameworkContent>

3.  ##### Import the Golem Widgets styles

    Load the CSS file directly in your HTML or import it in your Sass/CSS file.

    ```scss
    @import '@golemui/gui-components/index.css';
    ```

4.  ##### Define a form and render it

    The easiest way to define a form is through the **Programmatic** API, using an array of `gui.*` shortcuts. Alternatively, the same form can be defined using the **JSON** API if you prefer.

    <Aside type="tip">Toggle the top-right dropdown to switch between JSON and Programmatic API examples.</Aside>

    <DslTabs>
      <Fragment slot="dx">
        <IntegrationTabs>
          <Fragment slot="react">
            ```ts
            import { gui } from '@golemui/gui-shared';
            import { GuiForm } from '@golemui/gui-react';

            const formDef = [gui.inputs.textInput('username')];
            const formData = { username: 'golemui' };
            const config = { formDef, data: formData };

            export function FormPage() {
              return (
                <div>
                  <GuiForm config={config} />
                </div>
              );
            }
            ```
          </Fragment>
          <Fragment slot="angular">
            ```ts
            import { Component } from '@angular/core';
            import { CommonModule } from '@angular/common';
            import { gui } from '@golemui/gui-shared';
            import { FormComponent } from '@golemui/gui-angular';

            @Component({
              imports: [CommonModule, FormComponent],
              selector: 'app-dynamic-form',
              template: `<gui-form [config]="config"></gui-form>`,
            })
            export class AppFormPage {
              protected config = {
                formDef: [gui.inputs.textInput('username')],
                data: { username: 'golemui' },
              };
            }
            ```
          </Fragment>
          <Fragment slot="lit">
            ```ts
            import { LitElement, html } from 'lit';
            import { customElement } from 'lit/decorators.js';
            import { gui } from '@golemui/gui-shared';
            import '@golemui/gui-lit';

            @customElement('lit-form')
            export class FormElement extends LitElement {
              config = {
                formDef: [gui.inputs.textInput('username')],
                data: { username: 'golemui' },
              };

              override createRenderRoot() {
                return this;
              }

              render() {
                return html`<gui-form .config=${this.config}></gui-form>`;
              }
            }
            ```
          </Fragment>
          <Fragment slot="vue">
            ```vue
            <script setup lang="ts">
            import { gui } from '@golemui/gui-shared';
            import { GuiForm } from '@golemui/gui-vue';

            const formDef = [gui.inputs.textInput('username')];
            const formData = { username: 'golemui' };
            const config = { formDef, data: formData };
            </script>

            <template>
              <div>
                <GuiForm :config="config" />
              </div>
            </template>
            ```
          </Fragment>
        </IntegrationTabs>

      </Fragment>
      <Fragment slot="json">
        Create a JSON file with your form definition and pass it to the form component:

        ```json
        {
          "form": [
            { "kind": "input", "type": "textinput", "path": "username" }
          ]
        }
        ```

        Then load and render it in your framework. See the [Integration](/integration/overview/) section for framework-specific setup.

      </Fragment>
    </DslTabs>

5.  ##### That's it

    Run your dev server and you'll see your form rendered in the browser.
