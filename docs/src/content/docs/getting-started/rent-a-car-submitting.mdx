The Reserve button currently uses `actionType: 'submit'`, which validates the form and emits through `formSubmit`. For this tutorial we'll switch it to a named `onClick` event instead — that routes the click through the standard `formEvent` callback so the application can read the data and react.

## Step 1 — Switch the button to a named event

Replace `actionType: 'submit'` with `onClick: () => 'handleReservation'`. The button no longer triggers automatic form validation on click; add `disabled: { when: '$formIsInvalid' }` if you want to keep the button locked until the form is clean.

## Step 2 — Listen for it

In your `formEvent` callback, match the event name and read `event.data`:

## Wrapping up

You've now built a real-world form that uses:

- declarative widget composition with `gui.layouts.grid` and `gui.layouts.flex`,
- validators per field,
- named states with `include` rules,
- a custom item renderer,
- async data loading with `onLoad`/`onFilter` and `inputDebounce`,
- form events to capture the submit.
