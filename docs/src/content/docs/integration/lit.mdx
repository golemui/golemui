## Installation

```bash
npm i @golemui/core @golemui/lit @golemui/gui-lit --save
```

## Styles

Import the core styles in your HTML or application entry point:

```scss
@import '@golemui/core/styles/index.css';
```

## Usage

<DslTabs>
  <Fragment slot="dx">
    ```ts
    import { LitElement, html } from 'lit';
    import { customElement } from 'lit/decorators.js';
    import { gui } from '@golemui/gui-shared';
    import { widgetLoaders } from '@golemui/gui-lit';

    @customElement('my-form')
    export class MyForm extends LitElement {
      formDef = [
        gui.inputs.textInput('username', { label: 'Username' }),
      ];
      formData = { username: '' };
      formConfig = { widgetLoaders };

      override createRenderRoot() {
        return this;
      }

      render() {
        return html`
          <gui-form
            .formDef=${this.formDef}
            .data=${this.formData}
            .formConfig=${this.formConfig}
          ></gui-form>
        `;
      }
    }
    ```

  </Fragment>

## `<gui-form>` properties

| Property               | Type                                                          | Description                                                                          |
| ---------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `.formDef` (required)  | `FormInput`                                                    | Programmatic `gui.*` array or parsed JSON form definition.                          |
| `.formSelectors`       | `GslSelectorsInput`                                            | GSL selector decorators. **Programmatic-only.**                                     |
| `.formConfig`          | `DxFormConfig`                                                 | DX engine wiring (loaders, item renderers, dependencies, validateOn, …). **Programmatic-only.** |
| `.data`                | `Record<string, any>`                                          | Initial form data.                                                                  |
| `.meta`                | `Record<string, any>`                                          | Out-of-band metadata you want to thread through events and state.                   |
| `.customWidgetLoaders` | `Core.WidgetLoaders<Type<Core.WithWidget>>`                    | Custom widget map; merged with the default Lit widget set.                          |
| `.itemRenderers`       | `Record<string, LitItemRenderer<any>>`                         | Custom item-renderer map (for dropdown, list, etc.).                                |
| `.customValidators`    | `CustomValidatorSchemas`                                       | Custom validator schemas referenced by `validator: { type: 'custom', ... }`.        |
| `.middlewares`         | `Core.Middleware<Core.State, Core.Action>[]`                   | Store middlewares (logging, persistence, devtools).                                 |
| `.validateOn`          | `Core.ValidateOn`                                              | When validation runs: `'eager'` (default), `'change'`, `'blur'`, `'submit'`, or an array. |
| `.dependencies`        | `Dependencies`                                                 | External helpers (e.g. a markdown parser).                                          |
| `.localization`        | `Core.I18nTranslator`                                          | Translator implementing the `I18nTranslator` interface.                             |
| `.autocomplete`        | `string`                                                       | Sets the underlying `<form>` element's `autocomplete` attribute.                    |

The element also dispatches two **custom events**:

| Event              | Detail type             | Description                                          |
| ------------------ | ----------------------- | ---------------------------------------------------- |
| `@formEvent`       | `Core.FormEvent`        | Fired when a widget fires a wired event.             |
| `@formHealth`      | `Core.FormHealth`       | Fired when the form's validation status changes.     |

See [Configuration](/integration/configuration/) for details on each property, plus the **Programmatic-only vs JSON-form** notes.

## Custom widgets in Lit

Build your own widgets by extending `LitElement`, consuming the form context with `@consume({ context: Lit.formContext })`, and providing the appropriate adapter (`@provide({ context: Lit.inputContext })` and friends). Because Lit widgets are native web components, they also work inside React or Angular hosts when paired with a thin shim. See [Extending GolemUI / Widgets](/extending/widgets/overview/) for the full walkthrough.
