GolemUI is **framework-agnostic** — your form definition runs unchanged in React, Angular, and Lit. Pick the adapter package for your framework; the form component, props, and behavior are identical across all three.

## Pick your framework

| Framework | Adapter package        | Component                    | Setup                                      |
| --------- | ---------------------- | ---------------------------- | ------------------------------------------ |
| React     | `@golemui/gui-react`   | `<FormComponent />`          | [React →](/integration/react/)             |
| Angular   | `@golemui/gui-angular` | `<gui-form>`                 | [Angular →](/integration/angular/)         |
| Lit       | `@golemui/gui-lit`     | `<gui-form>` (web component) | [Lit →](/integration/lit/)                 |

## What `<gui-form>` does

- Renders widgets from your `formDef` array (Programmatic or JSON).
- Tracks user input in a reactive store.
- Runs validators and surfaces errors.
- Emits events your application code listens to.

Every customization knob — widget loaders, item renderers, validators, middlewares, i18n, dependencies, states — flows through the same small surface. See [Features Overview](/features/overview/) for the full list of inputs and [Configuration](/integration/configuration/) for the per-prop reference.

<Aside type="tip">
Switching frameworks later only requires changing the adapter package and the component wiring — your form definitions and business logic stay identical.
</Aside>
