## Installation

```bash
npm i @golemui/core @golemui/angular @golemui/gui-angular --save
```

## Styles

Import the core styles in your `styles.scss` or `angular.json`:

```scss
@import '@golemui/core/styles/index.css';
```

## Usage

<DslTabs>
  <Fragment slot="dx">
    ```ts
    import { Component } from '@angular/core';
    import { CommonModule } from '@angular/common';
    import { gui } from '@golemui/gui-shared';
    import { FormComponent, widgetLoaders } from '@golemui/gui-angular';

    @Component({
      imports: [CommonModule, FormComponent],
      selector: 'app-my-form',
      template: `<gui-form
        [formDef]="formDef"
        [data]="formData"
        [formConfig]="formConfig"
      ></gui-form>`,
    })
    export class MyFormComponent {
      protected formDef = [

      protected formData = { username: '' };
      protected formConfig = { widgetLoaders };
    }
    ```

## `<gui-form>` inputs

| Input                 | Type                                               | Description                                                                                     |
| --------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `formDef` (required)  | `FormInput`                                        | Programmatic `gui.*` array or parsed JSON form definition.                                      |
| `formSelectors`       | `GslSelectorsInput`                                | GSL selector decorators. **Programmatic-only.**                                                 |
| `formConfig`          | `DxFormConfig`                                     | DX engine wiring (loaders, item renderers, dependencies, validateOn, …). **Programmatic-only.** |
| `data`                | `Record<string, any>`                              | Initial form data.                                                                              |
| `meta`                | `Record<string, any>`                              | Out-of-band metadata you want to thread through events and state.                               |
| `customWidgetLoaders` | `Core.WidgetLoaders<Type<Core.WithWidget>>`        | Custom widget map; merged with the default Angular widget set.                                  |
| `itemRenderers`       | `Record<string, Angular.AngularItemRenderer<any>>` | Custom item-renderer map (for dropdown, list, etc.).                                            |
| `customValidators`    | `CustomValidatorSchemas`                           | Custom validator schemas referenced by `validator: { type: 'custom', ... }`.                    |
| `middlewares`         | `Core.Middleware<Core.State, Core.Action>[]`       | Store middlewares (logging, persistence, devtools).                                             |
| `validateOn`          | `Core.ValidateOn`                                  | When validation runs: `'eager'` (default), `'change'`, `'blur'`, `'submit'`, or an array.       |
| `dependencies`        | `Dependencies`                                     | External helpers (e.g. a markdown parser).                                                      |
| `localization`        | `Core.I18nTranslator`                              | Translator implementing the `I18nTranslator` interface.                                         |
| `autocomplete`        | `string`                                           | Sets the underlying `<form>` element's `autocomplete` attribute.                                |

The component also exposes two **outputs**:

| Output         | Type              | Description                                        |
| -------------- | ----------------- | -------------------------------------------------- |
| `(formEvent)`  | `Core.FormEvent`  | Emitted when a widget fires a wired event.         |
| `(formHealth)` | `Core.FormHealth` | Emitted when the form's validation status changes. |

See [Configuration](/integration/configuration/) for details on each input, plus the **Programmatic-only vs JSON-form** notes.

## Custom widgets in Angular

Build your own widgets by implementing `Core.WithWidget` and injecting one of the framework's `*WidgetAdapter` services (`InputWidgetAdapter`, `LayoutWidgetAdapter`, `DisplayWidgetAdapter`, `ActionWidgetAdapter`) in your constructor. The adapter handles `init` / `destroy` and exposes a reactive `templateData` signal. See [Extending GolemUI / Widgets](/extending/widgets/overview/) for the full walkthrough.
